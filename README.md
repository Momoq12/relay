# relay

Displays messages from one discord server to another.

use the ".say" prefix in corresponding relay channel of your own relay discord server to send messages to the said server.

# setup

Replace the placeholder in .env file with your own tokens WITHOUT THE QUOTATION MARKS


Example:

BOT_TOKEN = ABCDEFGHIJKLMNOPQRSTUVWXYZ

READER_TOKEN = ABCDEFGHIJKLMNOPQRSTUVWXYZ
